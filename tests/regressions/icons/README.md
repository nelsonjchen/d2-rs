# Icon placement regressions

New inputs for the pinned D2 v0.9.0 icon initialization, placement and compound
clone lifecycle. The SVG icon is a locally authored solid square embedded as a
data URI, so measurement and layout require no remote asset access. The input
combines automatic and explicit icon positions with nested containers and
cross-container edges. Exact output comparisons cover this input, not full
icon rendering or direct engine reconstruction.
