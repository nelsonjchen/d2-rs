the private `nelsonjchen/d2-rs-history` repository.

## render (second pass: scoreboard captures and renderer probes)

No fixture in this family was retired. The remaining 48 tracked
`crates/d2-rs-render/tests/fixtures/*` artifacts are regenerated by two new
recipe files:

- `tools/fixtures/renderexport-render-api.toml`: the scoreboard captures
  (`color-api`, `svg-api`, `themes-api`, `svg-admission-api`,
  `svg-structural-api`, `svg-labels-api`, `svg-font-api`,
  `renderer-admission-sketch`) through `scripts/render_scoreboard_fixtures.py`
  (go overlay via `scripts/upstream_overlay.py`), `color-positions-api`
  (hook `render-color-positions`, hand-written witness seed
  `tools/fixtures/seeds/render-color/positions.json`), and the d2js raw-target
  captures `public-target-v090` / `public-target-precision-v090`
  (`tools/d2js-capture/render-public-target.mjs`, after `d2js-node-package`).
- `tools/fixtures/renderexport-render-probes.toml`: the v0.9.0-era renderer
  probes, harvested from `../d2-v0.9.0-trace` (`*_probe_test.go`,
  `codex_*_test.go`, root `*.overlay`) and `.reference/*/source-module` /
  `tools/probes`, retargeted to the pin. Grids are inlined in the hooks or
  expanded by `scripts/render_probe_fixtures.py`; hand-written D2 sources and
  witness lists are the seeds `tools/fixtures/seeds/render-probes.json`,
  `render-markdown-flow.json`, `render-edge-icon-positions.json` and
  `render-mime-registration.json` (about 20 KB together). d2lib-compiled
  fixtures use the `render-compile-probe` hook (TALA seed 1, or dagre/ELK as
  the original probes did); `legend-connection-errors` and
  `scene-label-admission` run the pinned upstream d2 CLI (PNG export).

Differences from the 9b706ac1 bytes that are metadata only (readers do not
read them): provenance/`source`/`source_commit`/`capture_script` strings now
name the pin and the recipe instead of v0.9.0 paths; CLI fixtures record
workdir-relative input paths and commands; success stderr ends in
`in ELAPSED` instead of a wall-clock duration (kept deterministic);
`connection-label-fill` `probe_stderr` holds the compiler error instead of a
local-path panic; JSON key order / number spelling (`47` vs `47.0`) in
`themes-api`, `xml-render-text`, `sketch-svg-source`, `markdown-background`,
`root-canvas-style`, `code-input-admission` and `sequence-note-references`.
All other fixtures regenerate byte-identically. Two `--force` runs give
identical artifacts.

Master drift (failing witness, Rust not changed):
`latex-input-admission-v090.json`. At the pin, `validateLatexInput` calls
`d2latex.ValidateInput`, which checks size before UTF-8 and reports
`latex input must be valid UTF-8` instead of v0.9.0's
`field "label" must be valid UTF-8` (8 rows differ, including
`utf8-before-size`, now a size error). Test:
`latex_admission::tests::original_latex_input_utf8_and_byte_boundaries`.

All payloads regenerate identically at the pin. Differences from the
9b706ac1 bytes are metadata only: JSON whitespace (`png-api`, `png`,
`static-png`), descriptive `source` strings (`composition-api`, `fonts-api`),
dropped capture-hash/count fields (`paint-api` `upstream_calls` /

`gif-frames-api` `calls_sha256`), an added `pin`, `result: null` on
`fonts-api` error rows, and `loop`/`disposal` on `timeline-api` frames.

Determinism: Go `t.TempDir()` roots are written as `@D2RS_TMP@/<Test>/<NNN>`
(the artwork replay substitutes a fresh directory, since its requests and
expected errors name that root), and tests that iterate a Go map literal
(`TestNativeBridgeOnlyTrueCrossings`, `TestNativeLanesLeaveNonoverlapsAndInvisibleRoutes`)
get canonically sorted operations. This fixed `artwork-api`, `geometry-api`
and `lanes-api`; two `--force` runs of every isometric recipe are byte-identical.
